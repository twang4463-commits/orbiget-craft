为什么需要

软件开发有工程化，内容创作有什么？

软件开发沉淀出了一门成熟学科——软件工程：文档、脚本、日志链、交付记录、复盘周报，都被组织成项目的资产。而内容创作至今没有对等的工程化方法论——做产品、做设计、做内容的个人创作者，大多还停在微信收藏夹 + 网盘 + Excel + 脑记忆的手工作坊阶段，过程散落各处、难以追溯与复用。Craft 把软件工程的这套思路，翻译成普通人也能用的轻量流程。

手工作坊式创作

零散 · 凭记忆 · 难追溯
01灵感碎片靠手写便签、手机备忘录随手记，散在各处，回头找不到。
02素材在微信、网盘、浏览器书签到处散落，加工时来回倒腾、版本混乱。
03交付靠微信发送或手动打包，传给谁、传了什么，没有记录。
04记录丢给Excel 手动维护，格式不一、更新滞后，等于又一份待整理的素材。
05复盘基本靠脑子回想，节奏、卡点、成长全凭感觉，无法复用。

核心能力

从采集到复盘，一条链路走完。

Craft 不是又一个写作工具，写作只是它的第一个场景。采集灵感 → 归集整理 → 工作台创作 → 一键交付 → AI 复盘，每一环都为「记录过程、复盘成果」服务，帮你把零散的创作动作变成可积累的资产。

01
⬇️

一键采集灵感

右键、划词、剪贴板、截图，四种入口随手收。自动抓取 OG / JSON-LD / citation 元数据，图片保留EXIF信息——素材从来不怕找不到出处。

02
📥

智能归集入库

采集的碎片先进收集箱，再按来源、主题自动打标签、结构化入库。归集不是堆文件夹，而是让每条素材随时可被检索、被召回。

03
✍️

场景化工作台

写作是第一个内置场景（小说 / 文章 / 文案），短剧、长文工作台各有独立布局。外壳不变，中间区随场景而变——每种创作都有自己的工作方法。

04
📤

规范交付导出

Markdown、PDF、压缩包，一键导出。交付时自动记录版本、接收方、时间戳，每一次交付都可追溯。创作成果随时可以离开工具——你的文字属于你自己。

05
✨

AI 辅助复盘

Agent 读你采集的素材和写下的字，做复盘、探索、答疑。确定的动作用按钮，不确定的方向用对话——采用 BYOK 模式（自带 API Key），你在设置页配置自己的大模型 Key（OpenAI / DeepSeek / 通义千问等），调用费用直接付给模型服务商，Craft 不收取任何 AI 相关费用。

06
🔒

本地优先+日志链

IndexedDB 作真相源，项目里的 .obit 快照自包含、可迁移；每条日志 SHA-256 链式自验证。任何篡改都会让日志链断裂，过程真实可追溯。

FAQ

常见问题。

运行时数据存在浏览器的 IndexedDB，项目快照写入你自己授权的工作区文件夹（通过 File System Access API）。Craft 没有自己的服务器——素材、文稿、日志默认全部留在你的设备上，流向由你决定：只有在你主动调用 AI 时，相关内容才会发给你选择的模型服务商（见 Q3）。换电脑也不用重新开始：你的全部项目就存放在自己电脑的一个文件夹里，跟普通文件一样，想备份想带走都随你——网盘、U 盘、移动硬盘都可以。到了新电脑再选一次这个文件夹，所有项目、素材、创作记录原样回来。

三步：① 从 Releases 页下载离线安装包并解压；② 浏览器地址栏打开 chrome://extensions，开启右上角「开发者模式」；③ 点「加载已解压的扩展程序」，选中解压目录即可。支持 Chrome 114+ 及 Edge 等 Chromium 内核浏览器，上架后可自动更新。

AI 功能采用 BYOK（Bring Your Own Key）模式：你需要在设置页配置自己的大模型 API Key（支持 OpenAI、Anthropic、DeepSeek、通义千问等主流模型），AI 调用直接在你的设备与模型服务商之间建立连接。Craft 不提供代理服务，不收取任何 AI 费用——你按模型服务商的定价付费，用多少花多少。仅调用 AI 时需要联网，其余所有功能完全离线可用。

笔记软件存「结果」，写作软件管「当下」，而 Craft 记录「过程」。每条素材的出处、每次修改的痕迹都进入可验证的日志链——三个月后回看，你不仅能看到成品，还能复盘它是怎么一步步长出来的，哪些灵感被用了，哪些被浪费了。
