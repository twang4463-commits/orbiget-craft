# 跨项目联动：创作资产网络的价值

> Craft 的真正价值不在「记录创作过程」，而在「让你的所有创作互相加速」。
>
> 记录只是地基。只有当多个项目之间能双向联动时，工具才从「写作助手」变成「创作资产网络」。

[五层创作模型](./01-five-layers.md) 把创作过程定义为资产：成品、过程碎片、创作记录，都是积累。那么一个问题自然出现——**资产只停在一个项目里，还是跟着你走？**

答案是后者。多项目联动不是功能清单上的一个卖点，而是资产逻辑的必然：素材、灵感、创作记录在项目之间流动、组合、反哺，跨项目的积累形成你自己的创作脉络。当这条脉络沉淀成作品、方法论、风格与知识体系，它就是你的个人 IP——这不是规划出来的路线，是资产积累的必然走向。

---

## 三层价值阶梯

### 第一层：单项目内全链路（入门价值）

采集 → 整理 → 创作 → 交付 → 复盘。一个项目里的创作过程被完整记录管理，素材和灵感不再散落在微信、网盘和记忆里。对轻度用户来说，停在这一层也够用。

### 第二层：跨项目联动（核心差异化）

不做孤岛，做网状资产体系。

流动的不只是成品——素材、灵感、创作记录都是资产（[什么是创作资产](./01-five-layers.md#什么是创作资产)），它们在项目之间组合、反哺。

举个例子：小说项目里的**大纲、角色、世界观**同步到短剧改编项目的**剧本、物料、排期**；短剧项目里的**对白创作、节奏调整、角色弧线打磨**反哺回小说项目，让原著角色更丰满。

```
       小说项目                    短剧项目
    ┌──────────┐              ┌──────────┐
    │ 大纲·角色·世界观 │──同步──→│ 剧本·物料·排期 │
    │  章节·日志·素材  │←──反哺──│  对白卡·分镜·笔记│
    └──────────┘              └──────────
         │                          │
         └──── 复盘 · 资产池 · AI Agent ────┘
```

三个关键特性：

- **双向**，不是单向复用。小说→短剧是正向，短剧→小说是反哺。
- **事件级同步**，不是文件拷贝。两边的事件（角色变更、章节完成、对白重写）可关联，日志链跨项目可见。
- **复盘跨项目**：AI 读的不只是一个项目，是「你在这个创作生态里干了什么」的全景。

### 第三层：跨项目延续（长期价值）

项目 A 的复盘结果成为项目 B 的起点。上一部小说写完，世界观缺了什么、哪个角色立不住——复盘结论自然带进下一部或衍生项目。

这不是文件夹管理，是你自己的创作脉络在延续：这一部的收获，成为下一部的起点。当这条脉络跨过足够多的项目，沉淀下来的就不只是作品，还有你的方法论、风格与知识体系——**个人 IP 就是这种积累的形态**。

---

## 成长路径

```
第一次创作 → 用起来（1~3 项目全功能）→ 跨项目联动（创作脉络连成网）→ 新阶段（更多项目，经营自己的创作 IP）
```

当创作资产织进网络——小说的角色同步到短剧，短剧的复盘反哺小说——工具的价值就在这个网络本身。这不是绑定，而是**这套资产网络已经成了创作的一部分**。
